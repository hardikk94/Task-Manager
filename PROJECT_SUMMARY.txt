================================================================================
                        📖 QUICK START GUIDE
================================================================================

FIRST TIME USERS:

Step 1: Register
  1. Run the application (./run.sh or python3 main.py)
  2. Select option "2" (Register)
  3. Enter a username (e.g., "john")
  4. Enter a password (minimum 4 characters)
  5. Confirm your password

Step 2: Login
  1. Select option "1" (Login)
  2. Enter your username
  3. Enter your password

Step 3: Try Task Manager
  1. From main menu, select "1" (Task Manager)
  2. Select "1" to add a task (e.g., "Buy groceries")
  3. Select "2" to view your tasks
  4. Select "3" to mark a task as completed
  5. Select "4" to delete a task
  6. Select "5" to go back

Step 4: Try Expense Tracker
  1. From main menu, select "2" (Expense Tracker)
  2. Select "3" then "1" to set a budget (e.g., $1000)
  3. Select "1" to add an expense
      - Category: "Food"
      - Amount: 50
      - Description: "Lunch"
  4. Select "2" to view all expenses
  5. Select "3" then "2" to check budget status
  6. Select "6" to view category summary
  7. Select "7" to go back

Step 5: Logout
  1. From main menu, select "3" (Logout)

================================================================================
                         💾 DATA STORAGE
================================================================================

All data is automatically stored in the "data/" directory:

  data/
    ├── users.json                     # User credentials (hashed passwords)
    ├── tasks.json                     # All users' tasks
    └── expenses/
        ├── {username}_expenses.csv    # User's expenses (CSV format)
        └── {username}_budget.txt      # User's monthly budget

Key Points:
  - Data is saved automatically after each operation
  - Each user's data is isolated and secure
  - Passwords are hashed using SHA-256 (not stored in plain text)
  - CSV files can be opened in Excel for analysis
  - The data/ directory is created automatically on first run
